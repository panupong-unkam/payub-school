⚙️ ฟังก์ชัน (Functions)

สร้าง "คำสั่งของเราเอง" เก็บโค้ดที่ใช้บ่อยไว้เรียกซ้ำ — โปรแกรมสั้นลง อ่านง่ายขึ้น

⏱️ ใช้เวลา ~60 นาที 📖 ระดับ: โครงสร้าง 💻 มีโค้ดให้ลอง

🎯 สิ่งที่จะได้เรียนรู้ในบทนี้

📌 หลังจบบทนี้ คุณจะ:

  • เข้าใจว่าฟังก์ชันคืออะไร และทำไมช่วยให้โค้ดดีขึ้น
  • สร้างฟังก์ชันที่ คืนค่า (return) และแบบ ไม่คืนค่า (void)
  • ส่ง พารามิเตอร์ (parameter) เข้าไปในฟังก์ชัน
  • เรียกใช้ฟังก์ชันหลายตัวร่วมกัน
  • แบ่งโปรแกรมใหญ่ ๆ เป็นชิ้นเล็ก ๆ ที่จัดการง่าย

🧩 1. ฟังก์ชันคืออะไร?

ฟังก์ชัน (Function) คือ "กล่องคำสั่ง" ที่เราตั้งชื่อ เก็บโค้ดไว้ข้างใน แล้วเรียกใช้เมื่อไหร่ก็ได้ — จริง ๆ แล้ว main() และ printf() ก็คือฟังก์ชัน!

📚
เปรียบเทียบ: เหมือน "เครื่องปั่นน้ำผลไม้" — เราใส่ผลไม้ (input/พารามิเตอร์) เครื่องทำงาน แล้วคืน น้ำผลไม้ (output/return) ออกมา โดยไม่ต้องรู้ว่าข้างในทำงานยังไง
C
int add(int a, int b) {
 │     │       │
ชนิดที่คืน ชื่อ  พารามิเตอร์
    return a + b;   // ส่งผลลัพธ์กลับ
}

↩️ 2. ฟังก์ชันที่คืนค่า (return)

เขียนฟังก์ชัน ก่อน main() แล้วเรียกใช้ใน main ค่าที่ return จะถูกส่งกลับไปแทนที่การเรียกฟังก์ชัน

🧪 ฟังก์ชันบวกเลข
⚠️
กฎง่าย ๆ: ในบทเรียนนี้ให้เขียนฟังก์ชัน ไว้ก่อน main() เสมอ เพื่อให้ main รู้จักฟังก์ชันนั้นก่อนเรียกใช้

📢 3. ฟังก์ชันแบบไม่คืนค่า (void)

บางฟังก์ชันแค่ "ทำงาน" (เช่น พิมพ์ข้อความ) ไม่ต้องคืนค่า ใช้ void นำหน้า

🧪 ฟังก์ชันวาดเส้นคั่น

🔗 4. ใช้หลายฟังก์ชันร่วมกัน

ฟังก์ชันเรียกใช้ฟังก์ชันอื่นได้ ทำให้แบ่งงานเป็นชิ้นเล็ก ๆ:

🧪 หาพื้นที่วงกลม
💡
DRY = Don't Repeat Yourself — ถ้าเขียนโค้ดเดิมซ้ำหลายที่ ให้ยกไปทำเป็นฟังก์ชัน แก้ครั้งเดียวมีผลทุกที่ที่เรียก

⚠️ 5. ข้อผิดพลาดที่พบบ่อย

❌
1. ชนิดที่คืนไม่ตรงกับ return 
int add(int a, int b) {
    printf("hi");   // ผิด! บอกว่าคืน int แต่ไม่ได้ return
}
❌
2. ส่งพารามิเตอร์ไม่ครบ/ผิดชนิด 
int add(int a, int b) { return a + b; }
add(5);        // ผิด! ต้องส่ง 2 ตัว
add(5, 3);     // ถูก ✓
❌
3. เขียนฟังก์ชันไว้หลัง main โดยไม่ประกาศก่อน — ในบทนี้ให้วางฟังก์ชัน ก่อน main() จะปลอดภัยที่สุด
