🤔 คำสั่งเงื่อนไข (if / else / switch)

สอนให้โปรแกรม "คิดและตัดสินใจ" — ถ้าเงื่อนไขจริงทำอย่างหนึ่ง ถ้าเท็จทำอีกอย่าง

⏱️ ใช้เวลา ~60 นาที 📖 ระดับ: ควบคุม 💻 มีโค้ดให้ลอง

🎯 สิ่งที่จะได้เรียนรู้ในบทนี้

📌 หลังจบบทนี้ คุณจะ:

  • ใช้ if เพื่อทำงานเมื่อเงื่อนไขเป็นจริง
  • ใช้ if...else เลือกทำ 2 ทาง
  • ใช้ if...else if...else เลือกได้หลายทาง (เช่น ตัดเกรด)
  • ใช้ switch...case เลือกตามค่าที่แน่นอน
  • เขียนโปรแกรมที่ตอบสนองต่างกันตามข้อมูลที่รับเข้ามา
💡
ทบทวน: เงื่อนไขใช้ตัวเปรียบเทียบจากหน่วยที่แล้ว (==, !=, >, <, >=, <=, &&, ||) โปรแกรมที่มี scanf อย่าลืมพิมพ์ค่าในช่อง ⌨️ Input ก่อนกดรัน

✅ 1. คำสั่ง if — "ถ้า...ก็..."

โครงสร้างพื้นฐาน: ถ้าเงื่อนไขในวงเล็บเป็นจริง ก็ทำคำสั่งในปีกกา

C
if (score >= 50) {
    printf("You pass!\n");
}

ถ้าจริงทำอย่างหนึ่ง ไม่งั้น (else) ทำอีกอย่าง — เลือกทางใดทางหนึ่งเสมอ

🪜 3. else if — เลือกหลายทาง

เมื่อมีหลายกรณี เช่น การตัดเกรด ใช้ else if ต่อกันเป็นขั้นบันได โปรแกรมจะเช็คจากบนลงล่าง เจอเงื่อนไขจริงตัวแรกก็ทำแล้วหยุด

C
if      (score >= 80) grade = 'A';
else if (score >= 70) grade = 'B';
else if (score >= 60) grade = 'C';
else                 grade = 'F';

🎛️ 4. switch...case — เลือกตามค่าที่แน่นอน

เมื่อต้องเทียบตัวแปรกับ ค่าเจาะจงหลาย ๆ ค่า (เช่น เลขวัน 1-7) switch อ่านง่ายกว่า else if ยาว ๆ

🧪 แปลงเลขเป็นชื่อวัน
⌨️ ค่าที่ป้อน (Input) — เลขวัน 1-7:
❌
อย่าลืม break;! ถ้าลืม โปรแกรมจะทำ case ถัดไปต่อไปเรื่อย ๆ (เรียกว่า "fall through") ส่วน default คือกรณีที่ไม่ตรง case ไหนเลย

⚠️ 5. ข้อผิดพลาดที่พบบ่อย

❌
1. ใช้ = แทน == 
if (x = 5)    // ผิด! นี่คือการกำหนดค่า (จริงเสมอ)
if (x == 5)   // ถูก ✓ เปรียบเทียบ
❌
2. ใส่ ; หลัง if ทันที 
if (score > 50);          // ผิด! บล็อกจบทันที
{ printf("pass"); }        // บรรทัดนี้ทำเสมอ
❌
3. ลืม break ใน switch ทำให้ผลลัพธ์ผิดเพราะ case ไหลต่อกัน
