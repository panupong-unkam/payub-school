📦 ตัวแปรและชนิดข้อมูล

เรียนรู้วิธีเก็บข้อมูล เช่น ตัวเลข ตัวอักษร ไว้ในโปรแกรม — เหมือนมี "กล่อง" ที่ตั้งชื่อได้

⏱️ ใช้เวลา ~50 นาที 📖 ระดับ: พื้นฐาน 💻 มีโค้ดให้ลอง

🎯 สิ่งที่จะได้เรียนรู้ในบทนี้

📌 หลังจบบทนี้ คุณจะ:

  • เข้าใจว่า ตัวแปร (variable) คืออะไร และทำไมต้องใช้
  • รู้จักชนิดข้อมูลหลัก: int, float, double, char
  • ประกาศ และ กำหนดค่า ตัวแปรได้ถูกต้อง
  • ใช้ รหัสรูปแบบ %d, %f, %c ใน printf ได้
  • รู้จัก const และกฎการตั้งชื่อตัวแปร
💡
หมายเหตุก่อนเริ่ม: ใน Try-it Editor ขอให้ใช้ ภาษาอังกฤษใน printf("...") เพราะ engine ในเบราว์เซอร์ยังไม่รองรับภาษาไทยใน string literal — แต่ comment ภาษาไทยใช้ได้ปกติ

📦 1. ตัวแปรคืออะไร?

ตัวแปร (Variable) คือ "กล่องเก็บข้อมูล" ที่เราตั้งชื่อได้เอง ใช้เก็บค่าต่าง ๆ ไว้ในหน่วยความจำของคอมพิวเตอร์ เพื่อเอามาใช้ทีหลัง

📚
เปรียบเทียบ: ลองนึกถึง กล่องใส่ของที่มีป้ายชื่อ — กล่องชื่อ age ใส่เลข 14, กล่องชื่อ grade ใส่ตัวอักษร 'A' เมื่ออยากรู้ว่าในกล่องมีอะไร ก็เรียกชื่อกล่องนั้น

โครงสร้างการสร้างตัวแปร มี 3 ส่วน:

C
int age = 14;
 │    │       │
ชนิด  ชื่อ    ค่าเริ่มต้น
🧪 ลองรันเอง — กล่องใบแรก

🔢 2. ชนิดข้อมูล (Data Types)

กล่องแต่ละใบเก็บของได้ "คนละแบบ" เราต้องบอกชนิดของกล่องตอนสร้าง:

ชนิด เก็บอะไร ตัวอย่างค่า
intจำนวนเต็ม0, 14, -25, 1000
floatทศนิยม (ความละเอียดปกติ)3.14, -0.5, 98.6
doubleทศนิยม (ละเอียดกว่า float)3.141592653
charตัวอักษร 1 ตัว (ใช้ ' ')'A', 'z', '5', '#'
⚠️
สังเกต: char ใช้ เครื่องหมายคำพูดเดี่ยว ' ' (เก็บได้ 1 ตัว) ส่วนข้อความยาว ๆ ใน printf ใช้ เครื่องหมายคำพูดคู่ " "
🧪 ลองรันเอง — กล่องทั้ง 4 ชนิด
💡
เลข f ต่อท้าย เช่น 1.65f บอกว่าค่านี้เป็น float ส่วน 3.14159 (ไม่มี f) เป็น double

🏷️ 3. รหัสรูปแบบใน printf

ตอนพิมพ์ค่าของตัวแปร เราต้องใช้ "รหัสรูปแบบ" (Format Specifier) เพื่อบอก printf ว่าจะเอาค่าชนิดไหนมาแทน:

รหัส ใช้กับชนิด ตัวอย่าง
%dintprintf("%d", 14) → 14
%ffloat / doubleprintf("%f", 3.14) → 3.140000
%.2fทศนิยม 2 ตำแหน่งprintf("%.2f", 3.14159) → 3.14
%ccharprintf("%c", 'A') → A
🧪 ลองเปลี่ยน %.2f เป็น %.0f หรือ %.4f ดู
⚠️
รหัสต้องตรงกับชนิด! ถ้าใช้ %d กับ float ผลลัพธ์จะเพี้ยน — จำง่าย ๆ: d=จำนวนเต็ม (digit), f=ทศนิยม (float), c=ตัวอักษร (char)

🧪 ลองรันเอง — ค่าเปลี่ยนไปเรื่อย ๆ

🔒 5. ค่าคงที่ (const) และการตั้งชื่อ

บางค่าเราไม่อยากให้เปลี่ยน เช่น ค่า Pi หรือจำนวนวันใน 1 สัปดาห์ ใช้คำว่า const นำหน้า จะกลายเป็น "ค่าคงที่" ที่แก้ไม่ได้:

C
const int DAYS_PER_WEEK = 7;
// DAYS_PER_WEEK = 8;  // ❌ Error! แก้ค่าคงที่ไม่ได้

📏 กฎการตั้งชื่อตัวแปร

  • ✅ ใช้ตัวอักษร a-z, A-Z, ตัวเลข 0-9 และ _ ได้
  • ✅ ต้องขึ้นต้นด้วย ตัวอักษร หรือ _ (ห้ามขึ้นต้นด้วยตัวเลข)
  • ❌ ห้ามมีเว้นวรรค เช่น my age → ต้องเขียน my_age หรือ myAge
  • ❌ ห้ามใช้คำสงวน เช่น int, return, if เป็นชื่อตัวแปร
  • 💡 ควรตั้งชื่อให้ สื่อความหมาย เช่น studentAge ดีกว่า x
✅ ชื่อที่ดี ❌ ชื่อที่ผิด
age2age (ขึ้นต้นด้วยเลข)
total_pricetotal price (มีเว้นวรรค)
myScorereturn (คำสงวน)

⚠️ 6. ข้อผิดพลาดที่พบบ่อย

❌
1. ใช้ตัวแปรก่อนประกาศ 
age = 14;        // ผิด! ยังไม่ได้บอกชนิด
int age = 14;    // ถูก ✓
❌
2. ใช้รหัสรูปแบบผิดชนิด 
float x = 3.5f;
printf("%d", x);   // ผิด! float ต้องใช้ %f
printf("%f", x);   // ถูก ✓
❌
3. char ใช้เครื่องหมายคำพูดผิด 
char g = "A";    // ผิด! char ใช้ ' ' ไม่ใช่ " "
char g = 'A';    // ถูก ✓

✏️ 7. แบบฝึกหัด

⭐ ง่าย โจทย์ที่ 1: บัตรประจำตัว

สร้างตัวแปร 3 ตัว แล้วพิมพ์ออกมา:

  • int age = อายุของคุณ
  • float height = ส่วนสูง (เมตร) เช่น 1.60
  • char section = ห้องเรียน เช่น 'A'

เขียนโปรแกรมแปลงอุณหภูมิจาก เซลเซียส เป็น ฟาเรนไฮต์
