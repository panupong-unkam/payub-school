🎓 ไฟล์ & โปรเจกต์จบหลักสูตร

บทสุดท้าย! รู้จักการอ่าน-เขียนไฟล์ และรวมทุกความรู้มาสร้างโปรแกรมจริง 3 โปรเจกต์

⏱️ ใช้เวลา ~75 นาที 📖 ระดับ: โปรเจกต์ 💻 มีโค้ดให้ลอง

🎯 สิ่งที่จะได้เรียนรู้ในบทนี้

📌 หลังจบบทนี้ คุณจะ:

  • เข้าใจแนวคิดการ อ่าน-เขียนไฟล์ ด้วย fopen, fprintf, fclose
  • รวมความรู้ทุกหน่วย (ตัวแปร, เงื่อนไข, ลูป, ฟังก์ชัน, อาร์เรย์) มาสร้างโปรแกรมจริง
  • สร้าง 3 มินิโปรเจกต์: เครื่องคิดเลข, เกมทายเลข, ระบบจัดการคะแนน
  • มีพื้นฐานพร้อมต่อยอดไปเรียน C ระดับสูง หรือภาษาอื่น
📌
เหมือนหน่วย struct: engine ในเบราว์เซอร์ ยังไม่รองรับการอ่าน-เขียนไฟล์ (ไม่มีระบบไฟล์) โค้ดไฟล์จึงเป็น "โค้ดอ้างอิง" ให้นำไปรันในคอมไพเลอร์จริง เช่น OnlineGDB หรือ Dev-C++ — แต่ 3 โปรเจกต์จบ รันได้จริงในเบราว์เซอร์!

📁 1. การอ่าน-เขียนไฟล์ (โค้ดอ้างอิง)

ที่ผ่านมา ข้อมูลหายไปเมื่อโปรแกรมปิด การเขียนไฟล์ทำให้ เก็บข้อมูลถาวร ได้ ขั้นตอนหลักมี 3 ส่วน: เปิด (fopen) → ทำงาน (อ่าน/เขียน) → ปิด (fclose)

✍️ เขียนลงไฟล์

C · โค้ดอ้างอิง 
#include <stdio.h>

int main() {
    FILE *f = fopen("score.txt", "w");  // "w" = write
    fprintf(f, "Somchai 85\n");
    fprintf(f, "Malee 92\n");
    fclose(f);                          // ต้องปิดเสมอ!
    printf("Saved to score.txt\n");
    return 0;
}

📖 อ่านจากไฟล์

C · โค้ดอ้างอิง 
FILE *f = fopen("score.txt", "r");  // "r" = read
char name[20];
int score;
while (fscanf(f, "%s %d", name, &score) != EOF) {
    printf("%s got %d\n", name, score);
}
fclose(f);
โหมด ความหมาย
"w"เขียน (ลบของเดิมทิ้ง)
"r"อ่านอย่างเดียว
"a"เขียนต่อท้าย (append)

🏆 2. โปรเจกต์จบหลักสูตร (รันได้จริง!)

ถึงเวลารวมทุกอย่างที่เรียนมา! 3 โปรแกรมนี้ ทำงานได้จริง — ลองรัน อ่านให้เข้าใจ แล้วดัดแปลงเพิ่มความสามารถของตัวเอง

🧮 โปรเจกต์ 1: เครื่องคิดเลข

ใช้: scanf + switch + ตัวดำเนินการ — รับเลข 2 ตัวและรหัสการคำนวณ (1=+ 2=− 3=× 4=÷)

🎲 โปรเจกต์ 2: เกมทายเลข

ใช้: ลูป + เงื่อนไข + break — เลขลับคือ 7 ผู้เล่นทายได้ 3 ครั้ง โปรแกรมบอกใบ้ สูง/ต่ำ
