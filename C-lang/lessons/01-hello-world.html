🚀 1. มาดูโปรแกรม C ตัวจริงกัน!

นี่คือโปรแกรม C ที่สั้นที่สุดและเป็น "คำทักทาย" ของโปรแกรมเมอร์ทั่วโลก:

C 
#include <stdio.h>

int main() {
    printf("Hello World!\n");
    return 0;
}

ลองรันดูเลย! กดปุ่ม "▶ รัน" ในกล่องด้านล่าง:

🧪 ลองรันเอง — โปรแกรมแรก
🎉
ยินดีด้วย! คุณเพิ่งรัน โปรแกรม C ตัวแรก ของคุณ! ถ้าเห็นข้อความ Hello World! ในกล่อง Output แปลว่าคุณทำสำเร็จ

🔍 2. มาดูทีละบรรทัด

โปรแกรมข้างบนมีเพียง 5 บรรทัด แต่มี 4 ส่วนสำคัญ ที่ต้องเข้าใจ:

บรรทัดที่ 1: #include <stdio.h>

✅ คือการ "ขอใช้" ความสามารถจากไฟล์ stdio.h (อ่านว่า "เอสทีดีไอโอ ดอท เอช")
📦 stdio ย่อมาจาก Standard Input/Output — รวมคำสั่งสำหรับ "อ่าน-เขียน" ข้อมูล เช่น printf, scanf

📚
เปรียบเทียบ: เหมือนเรา "ยืมเครื่องมือจากกล่องเครื่องมือ" — ถ้าไม่ยืมเครื่องมือนี้ เราจะใช้ printf ไม่ได้!

บรรทัดที่ 3: int main()

✅ main() คือ "จุดเริ่มต้น" ของทุกโปรแกรม C
🚀 คอมพิวเตอร์จะเริ่มอ่านโปรแกรมจาก main เสมอ
🔢 int หมายความว่าฟังก์ชันนี้จะคืนค่าเป็นเลขจำนวนเต็ม (Integer)

บรรทัดที่ 4: printf("Hello World!\n");

✅ printf = print + format = "พิมพ์แบบจัดรูปแบบ"
📺 พิมพ์ข้อความที่อยู่ใน " " ออกหน้าจอ
↩️ \n หมายถึง "ขึ้นบรรทัดใหม่" (Newline)

⚠️
อย่าลืม! ต้องใส่ ; (semicolon) ที่ท้ายคำสั่ง เหมือนเครื่องหมาย "จบประโยค" ในภาษาอังกฤษ — ถ้าลืม โปรแกรมจะรันไม่ได้!

บรรทัดที่ 5: return 0;

✅ บอกว่า "โปรแกรมจบ และทุกอย่างเรียบร้อยดี"
0️⃣ เลข 0 = "สำเร็จ" / ตัวเลขอื่น = "มีข้อผิดพลาด"

✏️ 3. ลองเปลี่ยนข้อความเองดู

ลองแก้ข้อความใน printf เป็นชื่อของคุณ แล้วกดรันดู:

🧪 ลองรันเอง — แสดงชื่อตัวเอง
💡
ลองพิมพ์ printf หลายบรรทัดก็ได้! แต่ละบรรทัดจะแสดงผลตามลำดับ

📐 4. รหัสพิเศษใน printf

ใน printf มีรหัสพิเศษที่เริ่มต้นด้วย \ (backslash) เรียกว่า "Escape Sequence"

รหัส ความหมาย ตัวอย่าง
\nขึ้นบรรทัดใหม่"A\nB" → A แล้วขึ้น B
\tเว้น Tab (ช่องว่างยาว)"A\tB" → A    B
\\พิมพ์เครื่องหมาย \"C:\\Users" → C:\Users
\"พิมพ์เครื่องหมาย ""\"Hi\"" → "Hi"
🧪 ลองใช้ \n และ \t

⚠️ 5. ข้อผิดพลาดที่พบบ่อย

❌
1. ลืม ; ท้ายบรรทัด 
printf("Hello")    // ผิด! ลืม ;
printf("Hello");   // ถูก ✓
❌
2. ลืม #include <stdio.h>
โปรแกรมจะ error ว่า "ไม่รู้จัก printf"
❌
3. ใช้เครื่องหมาย " ผิด 
printf('Hello');   // ผิด! ต้องใช้ " ไม่ใช่ '
printf("Hello");   // ถูก ✓
❌
4. ตัวพิมพ์เล็ก-ใหญ่ผิด 
Printf("Hello");   // ผิด! P ต้องเป็นตัวเล็ก
printf("Hello");   // ถูก ✓
ภาษา C case-sensitive — ตัวพิมพ์ใหญ่/เล็ก คือคนละตัว!

✏️ 6. แบบฝึกหัด

⭐ ง่าย โจทย์ที่ 1: ทักทายตัวเอง

เขียนโปรแกรมที่แสดงข้อความ 2 บรรทัด:

  • บรรทัดที่ 1: สวัสดีครับ ผมชื่อ [ชื่อของคุณ]
  • บรรทัดที่ 2: ยินดีที่ได้รู้จัก!
💻 พื้นที่เขียนโค้ด
⭐⭐ ปานกลาง โจทย์ที่ 2: ตารางข้อมูลส่วนตัว

เขียนโปรแกรมแสดงข้อมูลในรูปแบบตาราง (ใช้ \t):

ชื่อ:    [ชื่อของคุณ]
อายุ:    [อายุ]
ชั้น:    [ม.อะไร]
งานอดิเรก: [งานอดิเรก]
💻 พื้นที่เขียนโค้ด
⭐⭐⭐ ท้าทาย โจทย์ที่ 3: วาดรูปสี่เหลี่ยม ASCII

เขียนโปรแกรมแสดงรูปสี่เหลี่ยมขนาด 5x3 ด้วยเครื่องหมาย *

*****
*   *
*****

💡 คำใบ้: ต้องใช้ printf หลายบรรทัด — และระวังการเว้นช่องว่าง!
