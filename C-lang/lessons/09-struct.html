🏗️ โครงสร้างข้อมูล (struct)

รวมข้อมูลหลายชนิดที่เกี่ยวข้องกันเป็น "ก้อนเดียว" เช่น นักเรียน 1 คน มีชื่อ อายุ และเกรด

⏱️ ใช้เวลา ~55 นาที 📖 ระดับ: ขั้นกลาง 💻 มีโค้ดให้ลอง

🎯 สิ่งที่จะได้เรียนรู้ในบทนี้

📌 หลังจบบทนี้ คุณจะ:

  • เข้าใจปัญหาของการใช้ตัวแปรแยก ๆ กับข้อมูลที่สัมพันธ์กัน
  • ประกาศ struct เพื่อรวมข้อมูลหลายชนิดเป็นชนิดใหม่
  • สร้างตัวแปรจาก struct และเข้าถึงสมาชิกด้วยเครื่องหมาย .
  • เข้าใจแนวคิด "หนึ่งเรคคอร์ด" (record) ที่ใช้ในฐานข้อมูลจริง
  • ฝึกแนวคิดเดียวกันด้วยโค้ดที่รันได้ในเบราว์เซอร์
📌
สำคัญ — อ่านก่อน! โปรแกรมรันโค้ดในเบราว์เซอร์ของเรา (engine เบา ๆ) ยังไม่รองรับคำสั่ง struct ดังนั้นในบทนี้:
  • 📘 โค้ด struct ของจริง จะแสดงเป็น "โค้ดอ้างอิง" (กล่องสีเข้ม มีปุ่มคัดลอก) — ให้นำไปรันในคอมไพเลอร์จริง เช่น OnlineGDB (คลิก) หรือ Dev-C++
  • 🧪 กล่อง Try-it (รันได้) จะใช้เทคนิค "ตัวแปร/อาร์เรย์คู่ขนาน" เพื่อฝึก แนวคิดเดียวกัน ในเบราว์เซอร์

😵 1. ปัญหา: ข้อมูลที่อยู่ด้วยกัน

สมมติเราเก็บข้อมูลนักเรียน 1 คน ที่มี ชื่อ, อายุ, และเกรด ถ้าใช้ตัวแปรแยก ๆ:

C
char name1[20];  int age1;  char grade1;
char name2[20];  int age2;  char grade2;
// ... มี 30 คน ต้องมี 90 ตัวแปร! ยุ่งมาก

พอมีหลายคนก็ยิ่งเละ — ข้อมูลของคนเดียวกันกระจัดกระจาย struct ช่วยแก้ปัญหานี้ด้วยการ "มัดรวม" ข้อมูลของ 1 คน ไว้เป็นก้อนเดียว

📦 2. ประกาศ struct (โค้ดอ้างอิง)

สร้าง "แม่แบบ" ของชนิดข้อมูลใหม่ ชื่อ Student ที่มีสมาชิก 3 อย่าง:

C · โค้ดอ้างอิง (รันในคอมไพเลอร์จริง) 
#include <stdio.h>

struct Student {
    char name[20];
    int  age;
    char grade;
};

int main() {
    struct Student s;
    strcpy(s.name, "Somchai");
    s.age = 14;
    s.grade = 'A';

    printf("Name: %s\n", s.name);
    printf("Age: %d\n", s.age);
    printf("Grade: %c\n", s.grade);
    return 0;
}
🔑
เข้าถึงสมาชิกด้วยจุด . — s.age อ่านว่า "age ของ s" เหมือนพูดว่า "อายุ ของ สมชาย" นั่นเอง

👥 3. อาร์เรย์ของ struct (โค้ดอ้างอิง)

พลังจริงของ struct: เก็บนักเรียนหลายคนด้วยอาร์เรย์ของ struct

C · โค้ดอ้างอิง 
struct Student students[3];

students[0].age = 14;
students[1].age = 15;
students[2].age = 13;

for (int i = 0; i < 3; i++) {
    printf("Student %d age = %d\n", i, students[i].age);
}

🧪 4. ฝึกแนวคิดในเบราว์เซอร์ — ตัวแปรคู่ขนาน

ก่อนมี struct โปรแกรมเมอร์ใช้ "ตัวแปรหลายตัวที่จับกลุ่มกัน" แทน 1 เรคคอร์ด กล่องนี้ รันได้จริง — เก็บข้อมูลนักเรียน 1 คนด้วยตัวแปรแยก:

🧪 โปรไฟล์นักเรียน (รันได้)

🧪 5. หลายเรคคอร์ด — อาร์เรย์คู่ขนาน (รันได้)

เก็บนักเรียนหลายคนด้วย อาร์เรย์ที่ index ตรงกัน: age[i] กับ grade[i] คือข้อมูลของนักเรียนคนที่ i (นี่คือ "แนวคิดเดียวกับอาร์เรย์ของ struct")

🧪 ตารางนักเรียน 3 คน (รันได้)
💡
struct ทำให้โค้ดนี้อ่านง่ายขึ้นมาก (เขียน student[i].age แทน age[i]) แต่ แนวคิดเบื้องหลังเหมือนกัน — มัดข้อมูลของ 1 คนไว้ด้วยกัน

✏️ 6. แบบฝึกหัด

⭐ ง่าย โจทย์ที่ 1: การ์ดหนังสือ

จำลอง 1 เรคคอร์ด "หนังสือ" ด้วยตัวแปรแยก: title (char[]), pages (int), price (float) แล้วพิมพ์ข้อมูลออกมาให้สวยงาม

💻 พื้นที่เขียนโค้ด (รันได้)
⭐⭐ ปานกลาง โจทย์ที่ 2: หาคนอายุมากที่สุด

มีนักเรียน 4 คน เก็บอายุใน age[4] และรหัสใน id[4] (index ตรงกัน) หาว่านักเรียน รหัสใด อายุมากที่สุด แล้วพิมพ์ออกมา

💻 พื้นที่เขียนโค้ด (รันได้)
⭐⭐⭐ ท้าทาย โจทย์ที่ 3: เขียน struct ของจริง

เขียนโปรแกรม struct ของจริง ชื่อ Point ที่มีสมาชิก x และ y สร้างจุด (3, 4) แล้วพิมพ์ออกมาเป็น (3, 4)

💡 กล่องนี้เป็น "โค้ดอ้างอิง" เขียนแล้วนำไปรันที่ OnlineGDB (engine ในเบราว์เซอร์รัน struct ไม่ได้)

C · เขียนแล้วรันที่ OnlineGDB 
#include <stdio.h>

struct Point {
    int x;
    int y;
};

int main() {
    struct Point p;
    p.x = 3;
    p.y = 4;
    printf("(%d, %d)\n", p.x, p.y);
    return 0;
}
