📊 อาร์เรย์ & สตริง

เก็บข้อมูลหลายค่าในตัวแปรเดียว เช่น คะแนนนักเรียน 30 คน หรือข้อความ 1 คำ

⏱️ ใช้เวลา ~60 นาที 📖 ระดับ: ข้อมูล 💻 มีโค้ดให้ลอง

🎯 สิ่งที่จะได้เรียนรู้ในบทนี้

📌 หลังจบบทนี้ คุณจะ:

  • สร้าง อาร์เรย์ (array) เพื่อเก็บข้อมูลหลายค่า
  • เข้าถึงข้อมูลด้วย ดัชนี (index) ที่เริ่มจาก 0
  • ใช้ลูปวนอ่าน/เขียนข้อมูลในอาร์เรย์
  • เข้าใจว่า สตริง (string) คืออาร์เรย์ของตัวอักษร
  • ใช้ %s และ strlen กับข้อความ
💡
ข้อควรรู้ของ engine นี้: เวลารับค่าเข้าอาร์เรย์ด้วย scanf ให้รับใส่ตัวแปรชั่วคราวก่อน แล้วค่อยเก็บลงช่องอาร์เรย์ (มีตัวอย่างในโจทย์) ส่วน printf("...") ยังใช้ภาษาอังกฤษ

📦 1. อาร์เรย์คืออะไร?

ถ้าตัวแปรคือ "กล่อง 1 ใบ" อาร์เรย์ก็คือ "แถวของกล่องที่ต่อกัน" ใช้ชื่อเดียว แต่มีหลายช่อง แต่ละช่องมีหมายเลข (index) เริ่มจาก 0

C
int scores[5] = {85, 72, 90, 68, 95};

index:    0    1    2    3    4
value:   85   72   90   68   95
                     │
            scores[2] คือ 90
🧪 เข้าถึงข้อมูลด้วย index
⚠️
index เริ่มที่ 0! อาร์เรย์ขนาด 5 มี index 0, 1, 2, 3, 4 — ไม่มี scores[5] (จะเกินขอบเขต ทำให้โปรแกรมพัง)

🔁 2. ใช้ลูปกับอาร์เรย์

พลังที่แท้จริงของอาร์เรย์เกิดเมื่อใช้คู่กับลูป — วนทำกับทุกช่องได้ในไม่กี่บรรทัด

🧪 หาผลรวมและค่าเฉลี่ย
🧪 หาค่ามากที่สุด

🔤 3. สตริง = อาร์เรย์ของตัวอักษร

สตริง (String) คือข้อความ ซึ่งจริง ๆ ก็คือ อาร์เรย์ของ char ปิดท้ายด้วยอักขระพิเศษ '\0' (null) ที่บอกว่า "จบข้อความแล้ว"

🧪 สร้างและพิมพ์สตริง
💡
%s ใช้พิมพ์สตริงทั้งคำ ส่วน strlen(name) นับจำนวนตัวอักษร (ต้อง #include <string.h> ก่อน)

⌨️ 4. รับสตริงจากผู้ใช้

ใช้ scanf("%s", name) — สังเกตว่า ไม่ต้องมี & หน้าชื่ออาร์เรย์!

🧪 ทักทายตามชื่อ
⌨️ ค่าที่ป้อน (Input) — ชื่อ (ภาษาอังกฤษ ไม่มีเว้นวรรค):
📚
scanf("%s") อ่านได้ทีละ "คำ" (หยุดเมื่อเจอเว้นวรรค) — ถ้าต้องการอ่านทั้งบรรทัดต้องใช้เทคนิคอื่นที่จะเรียนในระดับสูงขึ้น

✏️ 5. แบบฝึกหัด

⭐ ง่าย โจทย์ที่ 1: พิมพ์อาร์เรย์ทีละช่อง

กำหนดอาร์เรย์ int a[5] = {10, 20, 30, 40, 50}; แล้วใช้ลูปพิมพ์ทุกค่าในรูปแบบ a[0] = 10
