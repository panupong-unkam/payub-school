➕ รับข้อมูล & ตัวดำเนินการ

ทำให้โปรแกรม "โต้ตอบ" กับผู้ใช้ได้ — รับค่าที่พิมพ์เข้ามา แล้วนำไปคำนวณ

🎯 สิ่งที่จะได้เรียนรู้ในบทนี้

📌 หลังจบบทนี้ คุณจะ:

  • ใช้ scanf รับค่าจากผู้ใช้ (จำนวนเต็มและทศนิยม)
  • ใช้ตัวดำเนินการคณิตศาสตร์ + - * / %
  • เข้าใจความต่างของ การหารจำนวนเต็ม กับ การหารทศนิยม
  • ใช้ตัวดำเนินการ เปรียบเทียบ และ ตรรกะ
  • เขียนโปรแกรมคำนวณที่รับค่าจากผู้ใช้จริง
💡
บทนี้มีกล่อง "Input" พิเศษ! โปรแกรมที่มี scanf จะมีช่อง ⌨️ ค่าที่ป้อน อยู่ใต้โค้ด — พิมพ์ค่าที่ต้องการทดสอบในช่องนั้น ก่อนกดรัน (แต่ละค่าขึ้นบรรทัดใหม่ หรือเว้นวรรค). ใน printf("...") ยังคงใช้ภาษาอังกฤษ

⌨️ 1. รับข้อมูลด้วย scanf

ที่ผ่านมาเราแค่ พิมพ์ออก (printf) ตอนนี้มาทำให้โปรแกรม รับค่าเข้า ได้บ้าง ด้วยคำสั่ง scanf (อ่านว่า "สแกนเอฟ")

C
int age;
scanf("%d", &age);
        │      │
      รหัสชนิด  & + ชื่อตัวแปร (อย่าลืม &!)
⚠️
ต้องมี & (ampersand) หน้าชื่อตัวแปรเสมอ! &age แปลว่า "ที่อยู่ของกล่อง age" — เพื่อบอก scanf ว่าให้เอาค่าไปใส่กล่องไหน (ยกเว้นตัวแปรข้อความ ซึ่งจะเรียนในหน่วยหลัง)

🧮 3. ตัวดำเนินการคณิตศาสตร์

ตัว ความหมาย ตัวอย่าง ผล
+บวก7 + 29
-ลบ7 - 25
*คูณ7 * 214
/หาร7 / 23 (!)
%เศษเหลือจากการหาร (modulo)7 % 21
🧪 เครื่องคิดเลขครบวงจร
📚
เครื่องหมาย % (modulo) มีประโยชน์มาก! เช่น เช็คเลขคู่-คี่: ถ้า n % 2 == 0 คือเลขคู่ / อยากพิมพ์ % ใน printf ต้องเขียน %%

⚠️ 4. กับดัก! การหารจำนวนเต็ม

7 / 2 ในภาษา C ได้ 3 ไม่ใช่ 3.5! เพราะเมื่อ จำนวนเต็ม ÷ จำนวนเต็ม ผลลัพธ์จะ ตัดเศษทิ้ง ถ้าอยากได้ทศนิยม ต้องมีตัวใดตัวหนึ่งเป็น float

🧪 เปรียบเทียบการหาร 2 แบบ
💡
(float)a เรียกว่า การแปลงชนิด (Type Casting) — บังคับให้ a กลายเป็นทศนิยมชั่วคราว

⚖️ 5. ตัวดำเนินการเปรียบเทียบ & ตรรกะ

ใช้ถามคำถามที่ตอบได้แค่ จริง (1) หรือ เท็จ (0) — สำคัญมากสำหรับหน่วยถัดไป (เงื่อนไข):

ตัว ความหมาย ตัวอย่าง (a=5, b=10)
==เท่ากับa == 5 → จริง
!=ไม่เท่ากับa != b → จริง
> <มากกว่า / น้อยกว่าa < b → จริง
>= <=มากกว่า/น้อยกว่าหรือเท่ากับa >= 5 → จริง
&&และ (AND) — จริงทั้งคู่a>0 && b>0 → จริง
||หรือ (OR) — จริงอย่างน้อย 1a>9 || b>9 → จริง
!ไม่ (NOT) — กลับค่า!(a==5) → เท็จ
🧪 ผลลัพธ์เป็น 1 (จริง) หรือ 0 (เท็จ)
❌
ระวังสับสน! = คือ "กำหนดค่า" ส่วน == คือ "เปรียบเทียบว่าเท่ากัน" — เขียน if(x = 5) กับ if(x == 5) ความหมายต่างกันมาก!
