🌱 โปรแกรมคืออะไร? ทำไมต้องเรียน C

ก่อนเขียนโค้ดจริง มาทำความรู้จักกับ "โปรแกรม" และ "ภาษา C" กันก่อน

⏱️ ใช้เวลา ~30 นาที 📖 ระดับ: เริ่มต้น ✅ ไม่ต้องเขียนโค้ด

🎯 สิ่งที่จะได้เรียนรู้ในบทนี้

📌 หลังจบบทนี้ คุณจะ:

  • เข้าใจว่า "โปรแกรม" และ "โปรแกรมเมอร์" คืออะไร
  • รู้จัก ภาษา C และเหตุผลที่เราต้องเรียน
  • มองเห็นภาพรวมหลักสูตรทั้งหมด
  • รู้จักเครื่องมือที่จะใช้เรียน (Playground บนเว็บ + Editor)

💡 1. โปรแกรมคืออะไร?

"โปรแกรม" คือ ชุดคำสั่ง ที่บอกให้คอมพิวเตอร์ทำอะไรบางอย่าง เหมือนเรา "สั่งงาน" คอมพิวเตอร์ทีละขั้นตอน

🍳
เปรียบเทียบง่าย ๆ: เวลาเราทำไข่ดาว เราทำตามขั้นตอน — ตอกไข่ → ใส่กระทะ → ใส่เกลือ → ตัก → กิน
โปรแกรมก็คือ "สูตรอาหาร" ที่เราเขียนไว้ให้คอมพิวเตอร์ทำตาม

ตัวอย่างโปรแกรมในชีวิตประจำวัน

  • 📱 แอป LINE / TikTok / YouTube — โปรแกรมบนมือถือ
  • 🎮 เกม ROV / Roblox / Minecraft — โปรแกรมที่สนุก
  • 🌐 เว็บไซต์ที่คุณกำลังเรียนอยู่นี้ — ก็เป็นโปรแกรม!
  • 🚗 ระบบในรถยนต์, ตู้ ATM, ไฟแดง — มีโปรแกรมอยู่ในนั้นทั้งหมด

📍 ทุกอย่างที่เป็น "อิเล็กทรอนิกส์" ส่วนใหญ่ทำงานด้วยโปรแกรม — และทั้งหมดนี้มีคน "เขียน" ขึ้นมา!

👨‍💻 2. โปรแกรมเมอร์ทำอะไร?

โปรแกรมเมอร์ คือ คนที่เขียนโปรแกรม — เปรียบเหมือน "นักเขียนสูตรอาหาร" ที่บอกคอมพิวเตอร์ว่าต้องทำอะไรบ้าง

💰
รู้หรือไม่? โปรแกรมเมอร์เป็นหนึ่งในอาชีพที่เป็นที่ต้องการมากที่สุดในปัจจุบัน และมีเงินเดือนเริ่มต้นสูง (~25,000-50,000 บาท สำหรับมือใหม่จบใหม่)

โปรแกรมเมอร์ใช้ "ภาษา" คุยกับคอมพิวเตอร์

คอมพิวเตอร์ไม่เข้าใจภาษาไทย/อังกฤษ — เราต้องใช้ "ภาษาโปรแกรม" ซึ่งมีหลายภาษา เช่น:

  • C ← บทเรียนของเรา!
  • Python ← ภาษายอดนิยมในปัจจุบัน
  • Java ← ใช้ทำแอป Android
  • JavaScript ← ใช้ทำเว็บไซต์
  • C++, C#, Swift, Go, Rust, ...

🤔 3. ทำไมต้องเรียน "ภาษา C"?

ภาษา C เป็นภาษาโปรแกรมที่ เก่าแก่ (สร้างปี ค.ศ. 1972 หรือเมื่อ 50+ ปีที่แล้ว!) แต่ยังใช้กันอย่างแพร่หลายจนถึงทุกวันนี้

เหตุผลที่ควรเรียน C

⚡
รวดเร็วและทรงพลัง
โปรแกรมที่เขียนด้วย C ทำงานเร็วกว่าภาษาอื่นเกือบทั้งหมด
🧠
เข้าใจคอมพิวเตอร์ลึก
เห็นการทำงานในระดับใกล้กับเครื่อง รู้ว่าคอมทำงานอย่างไรจริง ๆ
🌍
ใช้สร้างของใหญ่ ๆ
Windows, Linux, iOS, เกม PS5, Microcontroller ใช้ C ทั้งสิ้น
🪜
เป็น "พื้นฐาน" ของภาษาอื่น
เรียน C แล้วเรียน C++, Java, Python, JavaScript จะง่ายขึ้นมาก
⚠️
แต่ก็ต้องบอกตรง ๆ ว่า: ภาษา C อาจจะ "ดูยากกว่า" Python นิดหน่อย เพราะต้องระวังเรื่องเล็ก ๆ น้อย ๆ (เช่น ลืม ; โปรแกรมก็รันไม่ได้) — แต่ ถ้าผ่านไปได้ คุณจะเก่งมาก ๆ! 💪

🗺️ 4. ภาพรวมหลักสูตรของเรา

เราจะเรียนทั้งหมด 11 หน่วย (รวมหน่วยนี้) จากง่ายไปยาก:

  1. หน่วย 0: ปฐมนิเทศ (ที่คุณกำลังอ่านอยู่นี้) 👈
  2. หน่วย 1: Hello World — โปรแกรมแรก
  3. หน่วย 2: ตัวแปร & ชนิดข้อมูล
  4. หน่วย 3: รับข้อมูล & ตัวดำเนินการ
  5. หน่วย 4: คำสั่งเงื่อนไข (if-else)
  6. หน่วย 5: การวนซ้ำ (for, while)
  7. หน่วย 6: ฟังก์ชัน
  8. หน่วย 7: อาร์เรย์ & สตริง
  9. หน่วย 8: พอยน์เตอร์
  10. หน่วย 9: struct
  11. หน่วย 10: ไฟล์ & โปรเจกต์จบ 🎓
💡
เคล็ดลับ: เรียนตามลำดับครับ! แต่ละบทจะใช้ความรู้จากบทก่อนหน้า ถ้าข้ามไปอาจจะงงได้

🛠️ 5. เครื่องมือที่จะใช้

1️⃣ Playground (ใช้บนเว็บไซต์นี้)

คุณ ไม่ต้องติดตั้งอะไรเลย! เพราะมี Playground ในตัวเว็บไซต์ — เปิดเบราว์เซอร์ก็เขียนโค้ดได้เลย

2️⃣ ในแต่ละบทเรียน จะมี "Try-it Editor"

กล่องเขียนโค้ดเล็ก ๆ ในบทเรียน ให้คุณลองแก้ลองรันได้ทันที

3️⃣ ถ้าอยากเขียนโค้ดที่บ้าน (ไม่บังคับ)

  • Code::Blocks — โปรแกรมฟรี ติดตั้งง่าย เหมาะกับมือใหม่
  • Dev-C++ — โปรแกรมฟรี สำหรับ Windows
  • VS Code + GCC — สำหรับคนที่อยากเริ่มแบบมืออาชีพ
📌
สำหรับบทเรียนนี้: เราจะใช้ Playground บนเว็บ เป็นหลัก เพราะใช้งานง่ายและไม่ต้องตั้งค่าอะไร

🌟 6. เคล็ดลับสำหรับมือใหม่

✅
1. อย่ากลัวที่จะลองผิดลองถูก — โปรแกรมเมอร์ทุกคน เริ่มจากการ "เขียนผิด" ทั้งนั้น
✅
2. ลองเขียนเองทุกครั้ง — อย่าแค่ดู! ลองพิมพ์ตามและรันดูจริง ๆ
✅
3. อ่าน Error Message — เมื่อโปรแกรมรันไม่ได้ ระบบจะบอกว่าผิดตรงไหน อ่านให้เข้าใจ
✅
4. ถามครู / ถามเพื่อน — ไม่เข้าใจอย่าเก็บไว้ ถามทันที!
