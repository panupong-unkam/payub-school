🥷 พอยน์เตอร์ (Pointers) — เบื้องต้น

เข้าใจ "ที่อยู่หน่วยความจำ" ด้วยภาพ — หัวข้อที่หลายคนกลัว แต่จริง ๆ ไม่ยากเลย!

⏱️ ใช้เวลา ~55 นาที 📖 ระดับ: ขั้นกลาง 💻 มีโค้ดให้ลอง

🎯 สิ่งที่จะได้เรียนรู้ในบทนี้

📌 หลังจบบทนี้ คุณจะ:

  • เข้าใจว่าตัวแปรทุกตัวมี "ที่อยู่" (address) ในหน่วยความจำ
  • ใช้ & เพื่อดูที่อยู่ และ * เพื่อดูค่าในที่อยู่นั้น
  • สร้าง พอยน์เตอร์ ที่เก็บที่อยู่ของตัวแปรอื่น
  • แก้ไขค่าตัวแปรผ่านพอยน์เตอร์
  • เข้าใจว่าทำไม scanf ต้องใช้ &

🏠 1. ตัวแปรมี "ที่อยู่"

ลองนึกภาพหน่วยความจำเป็น "ตึกที่มีห้องเรียงกัน แต่ละห้องมีเลขที่" เวลาสร้างตัวแปร คอมพิวเตอร์จะจองห้องหนึ่งให้ — ห้องนั้นมี เลขที่ (address) และมี ของข้างใน (value)

แผนภาพ
ตัวแปร:   int age = 14;

หน่วยความจำ:
  ┌─────────────┐
  │  ห้อง #1000  │  ← address (ที่อยู่) เขียนด้วย &age
  │    [ 14 ]    │  ← value (ค่า) เขียนด้วย age
  └─────────────┘
  • age = ค่าในห้อง (14)
  • &age = ที่อยู่ของห้อง (เช่น #1000)

👉 2. พอยน์เตอร์ = ตัวแปรที่เก็บ "ที่อยู่"

พอยน์เตอร์ (Pointer) คือตัวแปรพิเศษที่เก็บ ที่อยู่ ของตัวแปรอื่น (ไม่ได้เก็บค่าตรง ๆ) ประกาศด้วย *:

C
int age = 14;
int *p = &age;   // p เก็บ "ที่อยู่ของ age"

printf("%d", age);   // 14 (ค่าตรง ๆ)
printf("%d", *p);    // 14 (ตามที่อยู่ไปเอาค่า)
📚
2 เครื่องหมายสำคัญ:
• & (address-of) = "ขอที่อยู่ของ..."
• * (dereference) = "ตามที่อยู่ไปเอาค่า" (เหมือนกดลิฟต์ไปที่ห้องนั้น)
🧪 พอยน์เตอร์ตัวแรก

✏️ 3. แก้ค่าตัวแปรผ่านพอยน์เตอร์

พลังของพอยน์เตอร์: เขียน *p = ค่าใหม่ จะไปแก้ค่าตัวแปรต้นทางได้เลย (เพราะ p รู้ที่อยู่ของมัน)

🧪 เปลี่ยนค่า age ผ่าน p
💡
สังเกต! เราไม่ได้แตะ age ตรง ๆ เลย แต่ค่ามันเปลี่ยน เพราะ *p = 20 ไปแก้ที่ห้องของ age

🔧 4. พอยน์เตอร์กับฟังก์ชัน (ของจริงที่ได้ใช้!)

ปกติฟังก์ชัน "คืนค่าได้ 1 ค่า" แต่ถ้าอยากให้ฟังก์ชัน แก้ค่าตัวแปรหลายตัว ต้องส่ง ที่อยู่ เข้าไป — นี่คือเหตุผลที่ฟังก์ชัน swap (สลับค่า) ต้องใช้พอยน์เตอร์

🧪 ฟังก์ชันสลับค่า 2 ตัวแปร
💡
อ๋อ! เข้าใจแล้ว scanf: ที่เราเขียน scanf("%d", &age) ใส่ & ก็เพราะ scanf ต้องรู้ "ที่อยู่" ของตัวแปร เพื่อจะเอาค่าที่ผู้ใช้พิมพ์ไปเก็บให้ถูกห้องนั่นเอง

⚠️ 5. ข้อผิดพลาดที่พบบ่อย

❌
1. สับสน * ตอนประกาศ กับตอนใช้ 
int *p = &x;   // ตอนประกาศ: * = "นี่คือพอยน์เตอร์"
*p = 5;        // ตอนใช้: * = "ตามที่อยู่ไปเอาค่า"
❌
2. ลืม & ตอนกำหนดที่อยู่ 
int *p = x;    // ผิด! x เป็นค่า ไม่ใช่ที่อยู่
int *p = &x;   // ถูก ✓
❌
3. ชนิดพอยน์เตอร์ต้องตรงกับตัวแปร — พอยน์เตอร์ของ int ต้องชี้ไปที่ตัวแปร int เท่านั้น (ไม่ใช่ float)

✏️ 6. แบบฝึกหัด

⭐ ง่าย โจทย์ที่ 1: อ่านค่าผ่านพอยน์เตอร์

สร้าง int score = 88; และพอยน์เตอร์ p ชี้ไปที่มัน แล้วพิมพ์ค่าผ่าน *p

💻 พื้นที่เขียนโค้ด
⭐⭐ ปานกลาง โจทย์ที่ 2: เพิ่มค่าผ่านพอยน์เตอร์

สร้าง int money = 100; และพอยน์เตอร์ p ชี้ไปที่มัน แล้วใช้ *p เพิ่มเงินอีก 50 (ไม่แตะ money ตรง ๆ) แล้วพิมพ์ money

💻 พื้นที่เขียนโค้ด
⭐⭐⭐ ท้าทาย โจทย์ที่ 3: ฟังก์ชันเพิ่มค่าเป็นสองเท่า

เขียนฟังก์ชัน void doubleIt(int *n) ที่ทำให้ค่าที่ n ชี้อยู่กลายเป็น 2 เท่า รับเลขจากผู้ใช้ เรียกฟังก์ชัน แล้วพิมพ์ผล
