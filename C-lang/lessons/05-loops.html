🔁 การวนซ้ำ (Loops)

ให้คอมพิวเตอร์ทำงานซ้ำ ๆ แทนเรา เช่น นับ 1-100 หรือพิมพ์สูตรคูณ ในไม่กี่บรรทัด

⏱️ ใช้เวลา ~60 นาที 📖 ระดับ: ควบคุม 💻 มีโค้ดให้ลอง

🎯 สิ่งที่จะได้เรียนรู้ในบทนี้

📌 หลังจบบทนี้ คุณจะ:

  • ใช้ for วนซ้ำตามจำนวนรอบที่รู้แน่นอน
  • ใช้ while และ do...while วนซ้ำตามเงื่อนไข
  • ใช้ break ออกจากลูป และ continue ข้ามรอบ
  • เขียน ลูปซ้อนลูป (nested loop) เช่น พิมพ์สูตรคูณ
  • ระวังและเลี่ยง ลูปไม่รู้จบ (infinite loop)

🔢 1. ลูป for — รู้จำนวนรอบแน่นอน

for เหมาะเมื่อรู้ว่าจะวนกี่รอบ มี 3 ส่วนในวงเล็บ คั่นด้วย ;

C
for (int i = 1; i <= 5; i++) {
       │            │        │
     เริ่มต้น      เงื่อนไข   เพิ่มค่า
    printf("%d ", i);
}
🧪 นับ 1 ถึง 10
💡
i++ คือการเพิ่มค่า i ทีละ 1 (ย่อจาก i = i + 1) — ถ้าอยากเพิ่มทีละ 2 ใช้ i += 2

🔄 2. ลูป while — วนตามเงื่อนไข

while วนซ้ำ ตราบเท่าที่เงื่อนไขยังเป็นจริง เหมาะเมื่อไม่รู้จำนวนรอบล่วงหน้า

🧪 นับถอยหลังจรวด
❌
ระวังลูปไม่รู้จบ! ถ้าลืม count-- เงื่อนไข count > 0 จะจริงตลอด โปรแกรมจะวนไม่หยุด — ต้องมีอะไรที่ทำให้เงื่อนไข "เปลี่ยนเป็นเท็จ" ในที่สุดเสมอ

🔁 3. ลูป do...while — ทำก่อนเช็คทีหลัง

คล้าย while แต่ ทำงาน 1 รอบก่อนเสมอ แล้วค่อยเช็คเงื่อนไข — เหมาะกับเมนูที่ต้องแสดงอย่างน้อย 1 ครั้ง

🧪 do...while

🚦 4. break และ continue

  • break = ออกจากลูปทันที (หยุดวน)
  • continue = ข้ามไปรอบถัดไป (ไม่ทำคำสั่งที่เหลือในรอบนี้)
🧪 พิมพ์เฉพาะเลขคี่ 1-9 แล้วหยุดที่เจอ 8

🎯 5. ลูปซ้อนลูป (Nested Loop)

ใส่ลูปไว้ในลูป — ลูปข้างในจะวนครบทุกรอบ ต่อ 1 รอบของลูปข้างนอก เหมาะกับตารางหรือรูปภาพ

🧪 สามเหลี่ยมดาว
💡
ลองเปลี่ยน printf("*") เป็นสูตรคูณ printf("%d ", row * star) ดูสิ!
