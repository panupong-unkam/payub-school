Hello World — โปรแกรมแรกของคุณ
โครงสร้างพื้นฐาน, #include, main(), printf และวิธีรันโค้ด
→
2✓
พื้นฐาน ⏱️ 3 คาบ 🔒 ล็อก
ตัวแปรและชนิดข้อมูล
int, float, double, char, const และวิธีตั้งชื่อตัวแปร
→
3✓
พื้นฐาน ⏱️ 3 คาบ 🔒 ล็อก
รับข้อมูล & ตัวดำเนินการ
รับ input ด้วย scanf, +-*/%, การเปรียบเทียบ, ตรรกะ
→
4✓
ควบคุม ⏱️ 4 คาบ 🔒 ล็อก
คำสั่งเงื่อนไข (if / else / switch)
ให้คอมพิวเตอร์ตัดสินใจเอง เช่น เปรียบเทียบคะแนน แล้วบอกผลสอบ
→
5✓
ควบคุม ⏱️ 4 คาบ 🔒 ล็อก
การวนซ้ำ (for / while / do-while)
ทำซ้ำคำสั่งหลายครั้ง เช่น นับเลข 1-100 พิมพ์ตารางสูตรคูณ
→
6✓
โครงสร้าง ⏱️ 4 คาบ 🔒 ล็อก
ฟังก์ชัน (Functions)
สร้างคำสั่งของเราเอง เช่น คำนวณเกรด() เรียกใช้ซ้ำได้
→
7✓
ข้อมูล ⏱️ 4 คาบ 🔒 ล็อก
อาร์เรย์ & สตริง
เก็บข้อมูลหลายค่าในตัวแปรเดียว เช่น คะแนนนักเรียน 30 คน
→
8✓
ขั้นกลาง ⏱️ 3 คาบ 🔒 ล็อก
พอยน์เตอร์ (Pointers) — เบื้องต้น
เข้าใจ "ที่อยู่หน่วยความจำ" ด้วยภาพ ไม่งงแน่นอน
→
9✓
ขั้นกลาง ⏱️ 3 คาบ 🔒 ล็อก
โครงสร้างข้อมูล (struct)
รวมข้อมูลหลายชนิดเป็นตัวเดียว เช่น นักเรียน{ชื่อ, อายุ, เกรด}
→
10✓
โปรเจกต์ ⏱️ 5 คาบ 🔒 ล็อก
ไฟล์ & โปรเจกต์จบหลักสูตร
อ่าน-เขียนไฟล์ และทำมินิโปรเจกต์ เช่น เครื่องคิดเลข, ทายตัวเลข, ระบบเกรด
→
